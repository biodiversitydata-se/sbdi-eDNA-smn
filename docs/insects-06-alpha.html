6B. Within-sample diversity (track B: insects)

Examine diversity within each sample — alpha diversity — using the Shannon index, complementing the between-sample comparison in step 5.

Select samples

Extraction methods can affect how many taxa are detected. To avoid mixing methods when comparing habitats, we use only lysate samples that pass the depth and date filters from step 3:

alpha_samples <- events[
  events$depth >= 100000 & !is.na(events$yday) & grepl("lysate", events$eventID),
]
nrow(alpha_samples)

Unlike in the previous analyses, we do not require matched sample pairs.

Subsample to a common depth

Samples with more reads may reveal more rare taxa, affecting diversity estimates. We therefore randomly subsample each to the same number of reads (rarefaction).

As in step 5, we work with clusters rather than individual ASVs:

alpha_ids <- duckdb_tibble(eventID = alpha_samples$eventID, .prudence = "stingy")

alpha_counts <- merged$counts |>
  semi_join(alpha_ids, by = "eventID") |>
  inner_join(clusters, by = "taxonID") |>
  summarise(quant = sum(organismQuantity, na.rm = TRUE), .by = c(eventID, cluster)) |>
  transmute(sample = eventID, taxon = cluster, quant)

set.seed(1)
alpha_rarefied <- el_rrarefy(alpha_counts)

el_rrarefy() works like rrarefy() in vegan. By default, it uses the smallest sample total as the common depth. set.seed() makes the random subsampling reproducible.

Unlike the other ecolongr functions used here, el_rrarefy() loads the data into R, which is manageable for this dataset.

Calculate Shannon diversity

The Shannon index measures both the number of taxa and how evenly their abundances are distributed. Higher values indicate greater within-sample diversity.

shannon <- el_diversity(alpha_rarefied, "shannon")
alpha_samples$shannon <- shannon[alpha_samples$eventID]

Plot Shannon diversity by habitat

plot_shannon <- function() {
  par(mar = c(7, 4, 2, 1))
  boxplot(alpha_samples$shannon ~ alpha_samples$habitat, las = 2, xlab = "",
          ylab = "Shannon diversity",
          col = habitat_cols[levels(factor(alpha_samples$habitat))])
}

plot_shannon()

Shannon diversity is broadly similar across habitats, with overlapping distributions.

This does not contradict the PCoA results in step 5. Beta diversity describes differences in community composition between samples, while alpha diversity describes diversity within each sample. Habitats can therefore have different communities but similar Shannon diversity.

Consider: Can two habitats have similar Shannon diversity even if they contain very different insect groups? What does this tell us about the difference between alpha and beta diversity?
