3B. Sample mapping (track B: marine plankton)

Explore where and when Baltic Sea samples were collected, and how salinity varies.

The two datasets contain 16S metabarcoding data of bacterioplankton from a transect sampled in July 2013 (KTH-2013-Baltic-16S) and monitoring stations sampled in 2019–2020 (PRJEB55296-16S).

Inspect sample metadata

merged$events contains one row per sample. We copy it to an ordinary data frame and label the datasets, using the dataset ID at the start of each eventID:

events <- as.data.frame(merged$events)
dataset_labels <- c("KTH-2013-Baltic-16S" = "2013", "PRJEB55296-16S" = "2019-2020")
events$dataset <- unname(dataset_labels[sub(":.*", "", events$eventID)])
table(events$dataset)

Check primers

Different primers may amplify different parts of the microbial community. We therefore check that both datasets used the same primers before comparing ASVs:

unique(events[c("dataset", "pcr_primer_name_forward", "pcr_primer_name_reverse")])

Both datasets use the same primers.

Prepare dates

Extract the month and day of year from eventDate:

event_start <- lubridate::parse_date_time(
  sub("/.*", "", events$eventDate),
  orders = c("ymd_HMSz", "ymd_HMS", "ymd_HM", "ymd"),
  quiet = TRUE
)
events$month <- lubridate::month(event_start)
events$yday  <- lubridate::yday(event_start)

Extract salinity

Salinity is stored in merged$emof, which has one row per sample and one column per contextual measurement. The two datasets use different names for salinity:

grep("salinity", colnames(merged$emof), value = TRUE)

We take salinity from salinity (psu) for the 2013 samples and from salinity_average (psu) for the 2019–2020 samples. The rows of emof are in the same order as those of events:

emof <- merged$emof
events$salinity <- ifelse(events$dataset == "2013",
                          emof$`salinity (psu)`, emof$`salinity_average (psu)`)
summary(events$salinity)

Some samples lack salinity measurements. They are shown with the smallest point size and excluded from later comparisons involving salinity.

Map samples

Plot the samples by month. Point colour indicates day of year, point size indicates salinity, and point shape distinguishes the datasets.

# Point size grows with salinity; missing values get the smallest size
point_size <- function(salinity, base, step) base + ifelse(is.na(salinity), 0, salinity / step)

color_yday <- colorRampPalette(
  c("#2c7fb8", "#addd8e", "#edf8b1", "#fa9fb5", "#2c7fb8")
)(366)
dataset_pch <- c("2013" = 21, "2019-2020" = 22)

plot_maps <- function(dataset) {
  in_dataset <- events[events$dataset == dataset, ]
  newmap <- rworldmap::getMap(resolution = "low")
  par(mfrow = c(4, 4), mar = c(2, 2, 3, 1), xpd = TRUE)

  for (m in 1:12) {
    in_month <- in_dataset[in_dataset$month %in% m, ]
    plot(newmap, xlim = c(10, 25), ylim = c(54, 66), asp = 1, main = month.abb[m])
    if (nrow(in_month) > 0) {
      points(in_month$decimalLongitude, in_month$decimalLatitude,
             pch = dataset_pch[dataset], col = "black",
             bg = color_yday[in_month$yday], cex = point_size(in_month$salinity, 1, 20))
    }
  }

  plot(1:366, rep(1, 366), col = color_yday, pch = "|", cex = 3,
       axes = FALSE, xlab = "", ylab = "", ylim = c(0.9, 1.3))
  axis(1, at = c(1, 182, 366))
  text(183, 1.2, "Day of year", cex = 1.2)

  plot(c(2, 18, 34), rep(1, 3), pch = 1, cex = 1 + c(2, 18, 34) / 20,
       xlim = c(-5, 40), ylim = c(0.9, 1.3), axes = FALSE, xlab = "", ylab = "")
  axis(1, at = c(2, 18, 34))
  text(18, 1.2, "Salinity", cex = 1.2)
}

plot_maps("2019-2020")

Use the same function to map the 2013 transect:

plot_maps("2013")

Click Zoom in RStudio’s Plots pane for a larger view.
