# sbdi-eDNA-smn
Tutorial for the hands-on workshop at the [first in-person Swedish Metabarcoding Network (SMN) meeting](https://metabarcoding.se/meeting-2026/), Uppsala, 8–9 December 2026. It shows how eDNA/metabarcoding data published through the [Swedish Biodiversity Data Infrastructure (SBDI)](https://biodiversitydata.se/) can be downloaded from the ASV portal and explored in R, with insects or marine plankton as alternative tracks.

Website: <https://biodiversitydata-se.github.io/sbdi-eDNA-smn/>

## Building the site

The files `tutorial_insects.R` and `tutorial_plankton.R` contain all the R code from each tutorial track, in the same order as on the website. They are generated automatically and can be used to run or test an entire track. **Do not edit these files manually.**

The figures are generated by running these scripts on real data. The data are not in this repository, so you need to download them first.

### Requirements

- R and the packages listed in step 1 of the tutorial.
- [Quarto](https://quarto.org/) (included in RStudio).
- The two ZIP files of each track, downloaded from the ASV portal, in one folder per track (insects and plankton).

### Build

**If you changed the R code** (including comments in code blocks), open a terminal in the repository folder and run:

```bash
export SMN_INSECTS=/path/to/insect-zip-files
export SMN_PLANKTON=/path/to/plankton-zip-files
./build_site.sh
```

The script automatically:
1. Extracts the R code from the tutorial pages into `tutorial_insects.R` and `tutorial_plankton.R`.
2. Runs the scripts to generate figures in `figures/`.
3. Builds the website in `docs/` using Quarto.

The data paths only need to be set once per terminal session. For subsequent builds, run `./build_site.sh`.

**If you only changed the text**, simply run:

```bash
quarto render
```

### Publishing

Commit and push your changes to publish the updated site through GitHub Pages.
